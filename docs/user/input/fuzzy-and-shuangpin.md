## 模糊音

九条：z/zh、c/ch、s/sh、n/l、f/h、l/r、an/ang、en/eng、in/ing。缺省全部关闭。

开启：输入法菜单「模糊音」子菜单勾选，或「偏好设置 → 模糊音」。开启 z/zh 后输入 `zi` 也出 知 / 之，开启 f/h 后输入 `kaiha` 也出 开发。
输入正确的词仍然优先，模糊匹配的词排在其后。韵母三条只对完整音节生效。

## 双拼

四套内置方案：小鹤、自然码、微软、搜狗，另有自己导入的自定义方案。在「偏好设置 → 通用」选择，留空为全拼。

- 拼音行显示解出的全拼（`nihc` → `ni'hao`），学习按全拼记录，切回全拼后同样受益。
- 零声母：小鹤 / 自然码写 `aa` `ai` `ah`（a、ai、ang）一族；微软 / 搜狗写 `o` + 韵母键（`oa` `ol` `oh`）。
- 微软 / 搜狗的 `;` 为 ing：输入拼音时末尾有落单的声母，`;` 作为拼音（`x;` → xing）；其他情况下仍为标点。
- 双拼下 v / u / i 均为音节键，[快捷输入](shortcuts.md) 中的算式与问字只能以 `?` 开头进入。
- 全拼输入 `lue` / `nue` 与词库形式 `lve` / `nve` 等价。双拼统一解为 `lve` / `nve`。
- 已知限制：`lo` 与 `luo` 同键，解为 luo。

### 自定义方案

「设置 → 通用 → 双拼」下拉的末尾有「自定义…」，选择一份 Rime 双拼方案文件（`.schema.yaml`）即可使用内置四套之外的键位。
导入在本地完成一次计算，之后使用与内置方案一样快，不依赖原文件。

- 只支持两键一音节的方案；方案里的其他规则（快捷键、标点、识别器）会被忽略并提示数量。
- 方案名与内置四套同名时会被拒绝，改名后再导入。
- 导入后的方案与内置方案并列在同一个下拉里，可随时切回或改用别的。
- 已知限制：只按方案的键位表解码，声母键沿用通用的 `v` `i` `u`（zh / ch / sh）。

方案文件是 Rime 的 `.schema.yaml`，读取 `schema` 的 `name`（方案名，不能与内置四套同名）与 `speller` 的 `algebra` 规则。

写法：每条规则把完整拼音改写成实际按键——`xform/样式/替换/` 里**替换串中的字母就是键**；`$1` 是括号里匹配到的部分原样放回（换声母保留后面的韵母 `v$1`，换韵母保留前面的声母 `$1s`）。一个音节跑完所有规则后剩下的两个字母，就是「声母键 + 韵母键」；零声母音节（`ai` / `an` / `en` 等）单独整条改写。最小的一份（`#` 注释行导入时忽略）：

```yaml
schema:
  schema_id: my-scheme
  name: 我的方案
speller:
  algebra:
    # $1 是括号里匹配到的部分，原样放回：换声母保留韵母（v$1），换韵母保留声母（$1s）
    # 声母 zh 打 v：zhong 改写成 vong
    - xform/^zh([a-z]*)$/v$1/
    # 韵母 ong 打 s：vong 改写成 vs
    - xform/^([a-z]*)ong$/$1s/
    # 零声母 ai 打 ad
    - xform/^ai$/ad/
```

上例的敲法：`zhong` → `vs`、`ai` → `ad`。完整方案就是把每个声母、每个韵母各写一条（`derive` 可一条出两种敲法，`abbrev` 产出简拼）。

- 规则只认 `xform` / `derive` / `abbrev` 三种；其余规则导入时提示「未支持」并跳过，不影响其余规则生效。
- `alphabet` 与 `initials` 两行可省略：青简只按 `algebra` 求值，Rime 现成方案里带着也不影响导入。
- 现成方案可从 Rime 社区的双拼方案仓库（如 rime-double-pinyin）取得。
